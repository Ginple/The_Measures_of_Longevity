## 可复建

Python 3环境：

```sh
pip install -r requirements.txt
python build.py
# 只需重建HTML/MD/索引时，到这里即可。
# 运行浏览器测试另需安装Chromium及系统依赖：
python -m playwright install --with-deps chromium
python qa.py
```

生成器读取 `manuscript.txt` 与 `legacy_anchors.json`，不依赖包外V5路径。`legacy_anchors.json`保留旧索引仅为复建；未在正文使用的条目不自动进入V6成品索引。manifest列出文件SHA256，manifest本身不自哈希。
