## C｜书稿架构方案对抗审计（A 三卷十一部 / B 八部保留 / C 混合）

**方案 A 的风险（按严重度排序）**：

1. **原创性表述风险（最高）**：第Ⅵ部"维护容量核算"与既有概念（生理储备 physiological reserve、 allostatic load、resilience/frailty index、可及性 care access）存在家族相似。**缓解**：正文必须把"容量核算"定位为**对既有概念的重组织与可算化**（如同 KERNEL 不变式措辞），并逐条对照储备/衰弱指数/allostatic load 的差异表；不得写"首次提出"。此项为**写作硬约束**，未通过则第Ⅵ部降级为普通综述章。
2. **章数超预算风险**：方案 A 36 章对 BOOK_PROPOSAL 原 30–36 章预算压线。缓解：第Ⅵ部六章与第Ⅶ部四章若素材不足即合并（预案 C 已备案）。
3. **V6/V7 素材映射完整性风险**：三卷重排时 V6 §18–21（向外）只占 3 章，存在素材丢失风险。缓解：定稿前做一次 V6/V7 逐章 → 新架构映射表（THE-227 验收条件之一）。
4. **价值章被机制章挤压**（V6 原始焦虑）。缓解：写作顺序保持第Ⅷ/Ⅸ部与第Ⅱ部并行起草（已在 MASTER §3 写作顺序中体现）。

**方案 B 的风险**：原创贡献无主场（已记录）；V7 深度与 V6 广度仍靠拼接。**维持原判断：B 不利于本书差异化。**

**方案 C 的风险**：32 章版本下第Ⅸ部"体验"压缩为 2 章会伤害 V6 第六部（艺术/意义/依赖）的完整性——V6 作者明确警示过"不应被机制怀疑排挤"。**缓解**：若启用 C，合并的对象应是第Ⅹ/Ⅺ部（行动与可修订），不是第Ⅷ/Ⅸ部。

**裁决**：A 为最优解，前提是上述 4 项缓解措施写入章节证据契约。

## D｜论文处置方案对抗审计（A 保持 / B 合并 P1+P2 / C +P4 / D +P5）

1. **合并（B）的可辩护性**：P1（身份映射）与 P2（汇总算子）共享 ΔM 记账与观测算子概念（KERNEL §2/§5 已统一）；合并后统一 estimand = "速度变化归属分解"（转换九），有 2026 实证缺口（TranslAGE/CHIP）支撑。风险：单篇过长、审稿面宽。缓解：形式化+模拟为主体，真实数据只作 motivating case（TPE 置换液对、CHIP 生长率），不作裁决。
2. **P4（容量核算）的独立性风险**：与书第Ⅵ部自我重叠——若书稿已完整论证，论文增量仅是形式化与反例集，可能不足独立贡献。**裁决**：P4 降为**条件立项**（原方案 C 的判定路径保留）：仅当①六模块反例能统一为一个可复用的核算框架、②有第二个可应用领域（如 P3 工具验证项目）时立项；否则留在书稿。**DEC-004 执行为 B+条件 C。**
3. **P5 不立项**：实验合同（THE-237）先走注册报告路径，不为它预占论文号 ✓（维持原案）。
4. **P3 维持原计划**：冻结协议优先级不变 ✓。

**裁决**：最优解 = **B（合并 P1+P2 为《Identifiability of Rejuvenation》）+ P4 条件立项 + P3 原计划 + P5 不占号**。
