# 示范模块B：检测到的突变变少，究竟改变了什么？
## A changing signal is not yet an identified biological change

**状态：机制与测量草稿，待人类与独立审阅，不覆盖V7原文。**

共享断言：**LON-C000002**。主书拟用位置：第三部身份与改变、第四部可见性的工程；与P1/P2的联系是研究设计约束，不是已证明的返老机制。

年龄相关信号可以很稳定，而它背后的解释仍需改变。Gupta等人的血液mtDNA研究分析了UK Biobank与All of Us的全基因组测序，输入736,038人，质控后620,385人。不同后续分析还有各自的分母，不能把这个总数直接放到每张图和每项检验下面。[原始研究](https://www.nature.com/articles/s41586-026-10569-6)

作者结合突变谱、遗传关联等结果，支持一个模型：低水平mtDNA变异原先可能低于bulk检测门槛，携带它的细胞随克隆性造血扩张后，变异才变得可见。这里应保留“支持模型”，而不是升级成“直接追踪并证实每个细胞都按此顺序改变”。研究明确指出，其分析来自bulk样本，无法恢复某一变异在每份样本各细胞间的异质性分布，也无法区分多个mtSNV来自一个克隆还是多个克隆。

一个简化的混合模型可说明为什么这项限制重要。设f为携带细胞比例，h为携带细胞内的突变比例，r为携带细胞相对非携带细胞的有效分子贡献，则在所声明的线性测量假设下：

`B = f·r·h / (f·r + 1 − f)`。

取f=0.5%、h=60%、r=1，汇总突变比例B为0.3%。若后来B降到0.15%，至少有三种可构造解释：h减半；f减半；或者f、h都不变而r降到约0.499。三者给出同一个终点，生物学意义却不同。这个算例只证明逆问题不唯一，**不是该论文的实测效应，也不是对任何抗衰干预的裁决**。

所以，后续研究不应仅问“指标降了多少”，还应问“携带细胞、细胞内比例、拷贝数、捕获和谱系各自发生了什么”。这些数据可以帮助区分竞争解释，但bulk信号本身不能补出缺失的配对身份，也不能把血液低水平变异的结果泛化为所有组织、所有致病mtDNA变异或所有线粒体功能。

**本模块不主张**：研究已经证明mtDNA普遍无害；克隆扩张解释了每个年龄相关变化；信号下降说明同一细胞返老；该标志物已有临床筛查净获益；本轮已获得单细胞配对金标。
