## 3. 一个经过精确计算的条件性结果

简化模型 `B=f*r*h/(f*r+1-f)`。基线f=1/200、h=3/5、r=1，B=3/1000。

同样的终点B=3/2000可以由以下三世界产生：

|世界|f|h|r|含义|
|---|---|---|---|---|
|A|1/200|3/10|1|携带细胞内比例改变|
|B|1/400|3/5|1|携带细胞比例改变|
|C|1/200|3/5|199/399|有效分子权重改变|

三个参数组合的终点使用Fraction算术精确相等。**这是条件性不可识别反例，不是新实测发现，不为真实试验分配机制概率，也不能直接推广到非线性时钟。**

这一视角把V6与V7接起来：前者追问保住什么能力，后者追问观察变化究竟允许推断什么；二者共同拒绝用一个总分替代对象、功能和价值。
