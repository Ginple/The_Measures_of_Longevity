# 三时点完整记录的条件性集合界：CALERIE 补表示例

2026-11-27；[代码](complete_case_bounds.py)及[穷举测试](test_complete_case_bounds.py)。这是使用报告的边际缺失数量进行**条件算术**，不是原始资料分析，不能作为作者实际建模的有效样本或临床估计。源为 [Warmbrunn 等](https://pmc.ncbi.nlm.nih.gov/articles/PMC13094879/) 与 [S3](https://ndownloader.figshare.com/files/61614040)；补充阅读及分母歧义见 [X60 审计](../CALERIE_WITHIN_TRIAL_WEIGHT_TRAJECTORIES_2026_AUDIT_2026-11-27.md)。

## 算法和前提

假设同一个由 N 个唯一参与者组成的固定总体，测量在三个固定时点，三组缺失集合分别为 A、B、C，其大小分别为 a、b、c。三时点均完整的人数为 `N−|A∪B∪C|`。在没有更多交集信息时：

`max(0, N−a−b−c) ≤ 完整人数 ≤ N−max(a,b,c)`。

下界源于并集大小不超过 N 或各集合大小之和；上界源于并集至少和最大集合一样大。两个端点均可构造：分别把缺失尽量分散至覆盖最多不同参与者，或让各缺失集合嵌套于最大集合中。脚本输出对应见证，测试穷举 N≤4 的三次测量所有缺失集合。若有已知两两交集、组别、变量缺失或删失规则，还可获得更窄的界；上述不是分组有效样本界，也不考虑组别/权重。

## 将报告数字置入这个假设

正文称190人为分析样本，S3 列胰岛素 AUC 的基线/12月/24月缺失数为57/33/6。如果**这三个数确实都在同一190个唯一参与者中定义**，三时点均可用的数量在 `max(0,190−57−33−6)=94` 与 `190−57=133` 之间，两个端点在数学上可达。

但这不是对真正三时点完成样本的断言。S3 对57列29.8%，而57/190是30.0%；统计分母、纳入规则、配对关系、个体交集和建模条件都未取得，固定总体假设未被验证。组内有效人数不能由总边际缺失推出。混合模型可以使用不同时间的部分观测；完整三时点人数既不等于该模型的总样本，也不等于模型中任何系数的有效样本。缺失多少、如何发生与是否有偏是不同问题，界限不识别缺失机制或偏倚方向。

运行：`python knowledge_base/experiments/complete_case_bounds.py`。此工具只处理精确计数，不能从四舍五入百分比推导精确人数，不处理抽样不确定性，也不校验研究数据的口径。
