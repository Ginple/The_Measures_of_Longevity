# 输入节律 × 剩余处理能力：一个离散人工反例

**仅为模型教学，不是动物或人体数据、临床安全阈值、建议给药节律或已有干预的效果估计。** 将[时间积压](../../longevity_capacity_timing/平均未超载_为什么仍会积压.md)与[维护者选择性](../../longevity_caretaker_selectivity/清除者也在靶标里_保留维护能力的年轻化.md)的接口并置；不是声称发现新排队定理或真实生物交互。

## 明确规则

两段相同长度的离散时段，单一货物，开始存量0，每段先一次性进入输入量 `a_t`，随后当段最多处理 `c`：

```
served_t = min(q_(t−1) + a_t, c)
q_t = q_(t−1) + a_t − served_t
score = q_1 + q_2
```

score 是两个时段**末尾库存快照的和**，单位是货物量，不是连续时间下真实的积压面积、平均等待、功能损害或个人风险。固定 `c` 可理解为这个任务的当段有效处理上限，不能简单等于细胞数；细胞可能代偿或增加功能。两种输入时序在两个时段的总输入均为2，初始存量一致；保留上限时两段累计处理2，减少上限时累计处理1.5、末期存量0.5。未在每格加入因干预产生的额外残骸。

| 输入时序 / 每段上限 | 保留上限 1.5 | 减少上限 0.75 |
|---|---:|---:|
| 均匀 (1,1) | q=(0,0), score 0 | q=(0.25,0.5), score 0.75 |
| 集中 (1.5,0.5) | q=(0,0), score 0 | q=(0.75,0.5), score 1.25 |

以 score 为预先指定结果，时序的差分别为保留上限时0、减少上限时0.5；差中差 `(1.25−0.75)−(0−0)=0.5`。这是对**人为固定因素和该尺度**的模型交互；不同结局或尺度可不同。两段后减少上限的两种时序都余0.5（最终存量相同），但第1段快照不同；仅看最终存量会漏掉这个例子的时序差。继续运行无输入则队列可清空，并非无限积累。上限被降低时，平均输入1大于0.75，不能拿本例证明平均输入小于上限时的任何结论。

## 若要在真实系统识别交互

有因果意义的对应问题需要定义可操作的输入时序与维护保护方案：在相同规定任务、总输入和窗口下，随机分配时序×保护/不保护（理想的2×2），以实验单位而非细胞/视野为随机单位；同时测实际输入时间与量、功能性服务和快照、末期存量、组织功能及伤害。保护与不保护本身可能改变输入、增加杀伤残余或改变任务类型，因而必须测这些中介而不是默认固定；方案本身的随机化可估计**方案效果**，要声称分离了纯粹的能力变化，还需要更强的干预特异性和机制假设，且不能按处理后的相同输入或保留程度筛选。

需要可行的随机化、干预一致性、无干扰或适当界定、盲法测量、预设时间和结果、缺失及死亡处理、足够功效，并报告效应及不确定性。若输入无法真正固定，这个精确模型只能生成比较问题，不代表可从观察关联识别机制。即使记录了积压，也必须独立测组织及人关心的功能与伤害。真实系统会有新接收者、时变服务、空间障碍、不同货物和反馈；此例刻意省略。

## 先行文献与跨尺度对照（2026-11-27 第 3 期补充）

- **排队与衰老死亡率**：[Ledberg 2020](https://doi.org/10.1371/journal.pone.0233384) 把损伤建模为排队系统（M/M/1 及 G/G/1），修复率随年龄下降；由 P(Q≥k)=ρ^k 推出死亡率随年龄指数上升。本例只是两时段的离散快照，**不扩展也不检验** Ledberg 的结果。正文引用时必须并列两者，不写“首次”（X85）。
- **饱和清除**：Karin/Alon 的 SR 模型里，清除 βX/(κ+X) 本身就是一种“有上限的处理能力”。本项目的 [SR 快照可识别性](SR_SNAPSHOT_IDENTIFIABILITY_2026-11-27.md) 在这一模型中说明：读数匹配并不意味着结局匹配。
- **系统层的真实例子**：[NBER w33491](https://www.nber.org/papers/w33491) 报告，日最高气温超过 34°C 时急诊与住院增加，热浪前已入院患者的死亡也增加。作者将其解释为拥堵外溢。这是社会系统的容量峰值，不是细胞清除的证据；本身也只是工作论文（X88）。
