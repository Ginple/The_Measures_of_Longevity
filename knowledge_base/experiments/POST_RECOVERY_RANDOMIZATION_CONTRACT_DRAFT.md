# 恢复后随机化：克隆选择性与正常再修复的测量合同草案

**地位：研究设计提案，不是已批准实验、已注册方案或医学方案。** 目标变量、可行平台、效应阈值、样本量、动物伦理与安全性均未确定。此草案是 THE-237 的工作输入，不关闭 D03/D04/D05/D07/D09，必须由实验、统计、伦理和独立审阅者共同修订。

## 1｜问题和可判定主张

在某一**明确规定**的损伤/恢复模型中，记忆相关异常克隆的初次损伤与恢复已发生；在确认残余首次暴露与损伤阶段满足预设条件后，随机给予候选干预或对照。该干预能否同时：

1. 减少后续预指定时间窗口内**异常克隆的绝对扩增**或异常输出；以及
2. 在第二次标准化挑战后，正常组织功能不比对照差超过预先确定的非劣界值；并
3. 不出现不可接受的净损害？

这不是“清除越多越好”，也不预设先清除后 OSK；某些记忆有维护价值。异常状态的判定不能只靠项目自定义年龄钟或单一标记。二次挑战可能是新损伤；必须先有明确临床/科研价值与伦理许可。

## 2｜目标试验协议：开始之前要锁定

| 元素 | 必填条件 | 不满足时 |
|---|---|---|
| 人群/对象 | 物种、性别、年龄、品系/供者、组织、疾病及初始损伤模型；明确目标和可获得人群 | 停；不跨物种借估计量 |
| 恢复和随机化零点 | 疗程结束，组织状态、首次损伤负荷、残余药效在预设阈值内；同一时间窗筛选，记录死亡/未恢复者 | 排除及原因公开；结果仅针对合格存活恢复者，不能推全初始群体 |
| 单位 | 优先以动物或独立供者为随机单位；培养皿/视野/克隆嵌套在单位和批次中 | 无独立重复时只能作可行性探索 |
| 干预与对照 | 指定候选、剂量/疗程、车辆、盲法、停药与洗脱；未选具体药物 | 停，不能由现有证据倒推“最佳药物” |
| 挑战 | 相同操作、剂量、时间、测量窗口；真实生物差异与伤害均要记录 | 不以二次挑战当无风险测量；伦理审批必须通过 |
| 监测 | 活体/血液最低侵入追踪、组织取样、长期异常增殖/肿瘤及感染，预设停止和救援 | 无可行监测则不执行 |
| 脱盲/污染 | 分配隐藏；检测/分型盲法；批次交错，记录意外揭盲和共同环境干扰 | 评估偏倚；不隐去偏离 |

## 3｜共同主要终点与 estimand

**克隆终点（优效）**：对随机化时确认存在且可追踪的预先定义异常克隆，比较随机后指定时点异常克隆**绝对数量或经验证的绝对输出**，采用 `log[(N_T+c)/(N_C+c)]`（仅当 c 的单位/选择在预注册中有生物和统计依据）。可使用供者/动物分层的模型；低于检测限需有计数模型或审定的区间处理，不凭 VAF 比例替代。这里的 N 是各随机单位的预设目标汇总或建模参数，必须事先定义；比值之比、组均值比和个体比不是同一 estimand。

**正常再修复终点（非劣）**：例如第二次挑战后预定时间的组织结构完整度、功能恢复或其他经验证结局 `Y`；方向先统一为越高越好。估计 `E[Y(干预) − Y(对照)]`，其双侧 95% CI 下界必须高于 `−Δ_NI`（等价于特定条件下单侧 2.5% 检验）；Δ_NI 须由有依据的历史效应、保留比例与临床价值决定，当前**未指定**。未达显著差异并不证明非劣。

**联合成功**：按预注册的多重性和联合检验规则，克隆终点达到优效且正常再修复达到非劣，才可声称同时满足两项。目标人群是随机化时全部合格单位；对停药、救援等若采用治疗策略，须尽可能继续测量结果。**死亡后不存在的修复或克隆指标不能直接采用“无论死亡如何均取原指标”的治疗策略**：各共同主要终点都须预先选择有意义的结局定义与死亡处理方案、列出 estimand 及其估计量。候选方案包括临床解释明确的死亡优先层级结局或其他复合结局，并分别报告死亡与功能/克隆组成；不同候选并非等价，不能默认继承原功能非劣界值，需重新制定可解释的非劣标准及方法。死亡是结局被截断，不能当作普通未观测值；活着但未测量才有独立的缺失数据问题。若另定义“无论分配哪组都存活者”的主层效应，其成员不可直接识别，单比较各组存活者需要额外假设或界限分析；详见[死亡截断反例](SURVIVAL_TRUNCATION_ESTIMAND_AUDIT_2026-11-27.md)。草案尚未选定最终策略和阈值，不可开始试验。

**安全约束**：严重不良事件、异常增殖、感染、慢性损伤等逐项与曝露时间/风险集并报；`零观察 ≠ 零风险`。不把探索性指标的非显著写成安全证明。小样本不足以排除罕见事件；统计阈值、追踪时间和利益风险决策必须由负责者预定义。

## 4｜身份、组成、绝对数与时间分辨

- **身份**：实验条形码/自然遗传标记验证克隆身份、碰撞和检测率。克隆身份≠同一物理细胞；耗竭型取样无法在前后对同一细胞作配对结论。若使用甲基化标记追踪，同时有可能受干预改写，需独立遗传参照与错分验证。
- **组成与数量**：对应组织分别采集活细胞浓度或绝对体积、类群分布、拷贝数、分选回收率、测序深度、阴阳对照。VAF 的分母受倍性、细胞数、CNV 与混合影响；无法换算绝对细胞数时报告范围及假设。
- **过程**：预定基线、恢复完成、随机化、干预中、洗脱后、第二挑战后多个点；同时记录产生、死亡、转移/脱落的观测代理。在 I6 的理想单状态、无新标记及常风险模型中，标签留存只约束成熟退出与其他丢失风险率之和；其他丢失可包含死亡，不能仅凭留存拆分各命运。若允许迁移、增殖、标记稀释或再进入，须另建对应模型与观测假设，不能直接沿用该总和结论。
- **选择偏差**：随机化前恢复者是条件化人群；干预后仅保留存活/可测的细胞又会引入处理影响的选择。优先总体随机单位估计，记录不可追踪原因，做预设敏感性分析；不能把每个克隆当随机化样本。
- **构成调整**：在因果图中区分组成是中介、混杂、协变量还是结果；干预后的组成不是天然的“噪声”，调整可能抹去真实治疗效应或产生偏差。未测共同原因不能由随机处理自动排除对中介—结果关系的混杂。

## 5｜控制、负控、偏差与可否证性

1. 车辆对照；首次损伤强度与恢复标准盲法核验，必要时测暴露与残留；第二次挑战的操作者与评估者盲法。若比较损伤首次干预与恢复后干预，两者不是天然等效：须独立随机并明确估计目标。
2. 预先确定正常与异常标记、绝对计数校准、同平台技术重复、跨批随机化、不同遗传参照及检测下限；重复采样可改变组织，需平衡并报告。
3. 同一平均标记变化可由细胞内改变、构成改变、选择存活或测量变更产生；如单细胞只能通过平行样本而不是同细胞配对，写“类群层面”而非“同一个细胞”。
4. 反例：异常克隆比例降低但绝对数量和疾病负担上升；正常修复均值改善但严重损害增加；表面状态年轻而再次挑战失败；治疗增加可测样本数量导致虚假扩张。预先模拟并测试管线识别能力。
5. 预设严重 AE、丢失、脱靶、伦理审查的暂停/停止条件；外部数据安全监督是否必要按风险与机构规定确定。

## 6｜功效、数据和实施门槛

- 目标单位层面的基线克隆负荷、变异、批次/供者相关性、纵向相关、追踪错误、死亡和失访率均待获取；根据共同主要终点、非劣界值及多重性做仿真功效，报告在最不利合理参数下的联合成功率。细胞数或癌细胞 pilot 方差不能代替供者/动物数。
- 先做不用于效应推断的可行性与测量验证，锁定版本；研究级数据保留校准、元数据、原始影像、盲态字典及处理日志，并遵守隐私、许可和伦理。原始数据、代码、协议和论文版本各存独立 hash；控制更改依赖和失效传播。
- 指定缺失机制下的主要分析，再做例如 MNAR 的 tipping-point 敏感性；基于可观察协变量的 IPW/插补需要正确模型与正值性。不得把所有失访说成随机。
- **未达成项**：尚无具体模型、人员、预算、审批、样本量、原始数据、独立审阅或正式登记；合同仅作可审查草图，不能作为执行指令。
