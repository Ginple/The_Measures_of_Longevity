# 摄取之后发生了什么：终端命运的条件性界限

2026-11-27｜人工质量守恒反例，不是实测，也不是对任何研究误差、疗效或偏倚的量化。与[源—接收证据审计](../SOURCE_RECIPIENT_CARDIAC_EVIDENCE_AUDIT_2026-11-27.md)相互链接。标准守恒代数的应用，不主张新的数学定理。

## 固定一个可追踪货物与边界

为一个指定追踪标签、接收细胞群和一个时间窗，假设期初量 `R0`、已进入接收群的累计量 `U`、期末仍在该群体内的量 `R1` 可以无误测量，且标签在边界内不额外生成。区分真正降解 `D` 和所有其他离开该群体的路径 `L`（例如再释放、转移或细胞离开），各量同单位、非负：

```
R1 = R0 + U − D − L
T = R0 + U − R1 = D + L
```

在只知道 `T≥0`，未约束 `L` 时，`D` 的**尖锐确定性范围**是 `[0,T]`。任意 `D` 在此区间都可令 `L=T−D` 得到非负满足守恒的见证；不在区间则违反非负。若可靠外部测量给出 `L∈[l,u]`，还要与 `[0,T]` 交集；可行时 `D∈[max(0,T−u), T−l]`。空集表示假设或输入至少有一项不一致，不应强行输出结果。若已知 `L=0`，`D=T` 才点识别。

## 两个不可由这些观测区分的人工世界

取 `R0=0, U=6, R1=2`，总离开接收群 `T=4`：世界 A `D=4,L=0`；世界 B `D=1,L=3`。摄取总量、期末存量均相同，真实降解相差4倍。两世界还可共同设定相同的细胞外收支：初始4、输入6、摄取6、期末4；在世界 B 中 `L=3` 作为移动到**其他不计入该细胞外分区的区域或细胞**，因此不违反这条收支。不是所有可能的 L 都能在保持该细胞外收支的同时成立；此处只声称以上两个特定见证成立，或将细胞外收支单独用于摄取测量，不拿它约束普遍界限。现实的摄取再释放可能返回同一细胞外区，从而需要将其显式并入细胞外收支。

见证只在每个时段的**累计量**层面成立，不指定瞬时流量、降解速率常数、分子产物或组织功能；可例如让摄取先发生、各出口随后发生。相同库存和摄取不表示实际生物世界必定存在这样的分流，亦不表明任一真实论文缺少额外的命运证据。示例 `[0,4]` 是在上述简化边界下的 D 范围，不是统计置信区间或数据推断。

## 测量和因果限定

荧光共定位或酸性区室定位可支持接触、内吞/递送，但不自动证明标签所代表的货物终端降解；荧光损失也可能是淬灭、漂白或标签从货物脱离。可考虑多位点稳定/可降解双标、追踪降解产物、校准淬灭及回收率、区分细胞迁移和再释放并设置正/负对照，但这些方案需要具体对象和方法验证。若标签被再合成、粒子异质、测量是相对蛋白信号而非守恒量，或边界/时点不同，此简化模型不直接适用。

即使追踪 D，也不能直接推知干预导致的功能改变：需随机化或有力因果设计、核对对象一致，测源端/接收端功能、毒性和外部路径。增加对真实系统的识别需要数据及实验，而非把本例数值代入。
