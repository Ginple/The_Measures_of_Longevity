# 共同组分约束：两时点联合界限

2026-11-27｜择取自 [PR #2 固定头 b8434e22](https://github.com/Ginple/The_Measures_of_Longevity/commit/b8434e22ec62ba21814546560a33fc38f4939e9f) 的 [备忘录](https://github.com/Ginple/The_Measures_of_Longevity/blob/b8434e22ec62ba21814546560a33fc38f4939e9f/papers/P2_weighting_observability/SHARED_COMPONENT_CONSTRAINT_2026-11-27.md)、代码和测试。与本分支既有[附加测量模型](P2_ADDITIONAL_MEASUREMENT_BOUNDS_2026-11-27.md)互补，不声明新定理或独立论文成果。

精确、无噪声、标准化两类模型为 `y_t=p_t*x1_t+(1-p_t)*x2`，`t=0,1`，`y_t,x1_t,x2∈[0,1]`，权重 `0<p_t≤1` 精确已知，并假定同一个 `x2∈[a,b]` 严格适用于两时点。对于 `p_t<1`，`0≤x1_t≤1` 要求 `(y_t-p_t)/(1-p_t)≤x2≤y_t/(1-p_t)`；`p_t=1` 时该点不约束 x2。与 `[a,b]` 相交，若为空即假设与观察联合不相容，不能投影为可行解。给定共同可行区间，`x1_1-x1_0` 是 x2 的仿射函数，在两个端点达到最小和最大；端点代回各时点即为可行见证，故界在这个确定性合同下可达。实现故意拒绝 p=0，不能直接使用该除法公式。

人工例：`p0=p1=1/2`、`y0=3/5,y1=2/5`，每时点类型2被限制在 `[2/5,3/5]`。无共同限制时的变化界为 `[-3/5,-1/5]`；要求同一个 x2 时点识别为 `-2/5`。如改为 `p1=1/3`，共同约束下仍有 `[-3/5,-2/5]` 的区间。另取 `p0=p1=1/2,y0=0,y1=1`，两时点各自可行但共同 x2 不存在；实现应报错。

[精确有理数实现](shared_type2_bounds.py)与[测试](test_shared_type2_bounds.py)择自 PR2；测试移至本分支实验套件并补充权重为1、单点可行区间的边界。有限网格与端点见证由同一开发过程构造，不是独立证明。这里 p 是线性混合权重，x2 是类型内数值，不是[捕获模型](PR2_CAPTURE_AND_SURVIVAL_BOUNDS_2026-11-27.md)的相对捕获效率或基础总体类别比例。

共同组分恒定是强假设，不是追踪到相同个体的证据；状态、处理、批次和测量变化均可破坏它。估计权重、噪声和测量区间需另建联合不确定性及敏感性分析，小 p 会放大误差。该例非真实生物数据、个体返老、临床效果或统计置信区间；独立数学审阅与真实应用未完成。
