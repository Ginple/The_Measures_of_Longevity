# 高穿透对抗研究：指标、身份、环境与决策之间不能偷换的接口

**性质**：2026-11-27 定向检索、选择性原文定位与同助手计算；不是系统综述、独立会审、临床建议或正式论文架构。研究卡编号 C000015–20 是暂存工作 ID，未接入研究保障引擎。外部网页仅工具解析；唯一获取并核验字节的外部来源是下述 GitHub 代码和许可证，**不是论文原文或试验原始数据**。读深、版本及待核均写在每卡中。

## 一｜本轮最重要的变化：不是“代理指标不好”，而是三种不同问题

1. **预测**：某指标在既有人群中区分未来风险吗？细胞组成研究中，多种甲基化时钟与未来事件相关，即使调整组成后关联仍在，不应把时钟一概说成“只是细胞比例”（C000017）。预测关联可以有用，但受基线状态、混杂与人群迁移约束。
2. **响应**：随机分配的干预是否改变该指标？这个问题应在相同时间、组织和算法版本上比较**组间对比**。某组前后显著、另一组不显著，不能推出干预组与对照组显著不同（C000015）。
3. **替代**：多种干预在指定场景改变该指标的幅度，能否预测其对临床结果及危害的效应？这是试验间与情境相关的验证命题；单项试验中同时改善两者，也不足以保证下一项干预。血压是药物干预与主要心血管事件之间证据较强的实例（C000018），**但该文不单独证明它是任何治疗、任何终点的正式验证替代终点**。

**对项目的修正**：先前强调代理失配是必要的，却容易滑向“分子读数不如功能”或“环境必然优先”。更可检验的主张是：**不同干预与语境需要不同测量组合，且能用明确的预测与决策性能考核其必要性。** 若一个低成本分子指标在预先指定的干预、人群和结局中可靠预测净临床收益，应该接受它的实践价值，而不是为框架保留例外。

## 二｜六张对抗证据卡

### C000015｜先看对照：二甲双胍、同一疾病领域、不同估计量

- **来源 A**：Corley 等，[Aging Cell 2024](https://pmc.ncbi.nlm.nih.gov/articles/PMC10776116/)，读摘要、Results/Discussion 和 Fig. 1 的工具解析文本。原始临床试验随机 12 人，对照是观察；事后单核细胞时钟分析报告 6 药物 vs 5 观察。药物组内 PCGrimAge 均值变化 −1.84 年（95% CI −3.03 至 −0.64），PCPhenoAge −3.53 年（−6.06 至 −0.99）；观察组各自组内检验未显著。**这不是已证明组间差**；多钟、后验、未盲观察和极小样本使推断脆弱。
- **来源 B**：Marcelo-Calvo 等，[METFORAGING 2026](https://pmc.ncbi.nlm.nih.gov/articles/PMC13098334/)，读摘要、Methods/Statistical analysis、Results 和 Fig. 2 文字。西班牙病毒抑制、无糖尿病且 ≥50 岁 HIV 人群；双盲随机 19 vs 21，96 周符合方案分析 17 vs 18。预设 PhenoAge EAA 调整后药物−安慰剂 −1.02 年（95% CI −5.30 至 +3.26；P=.627）。无正式功效计算，低于目标 60，完成治疗者分析不是完整 ITT，未作敏感性分析；11 指标未作多重比较调整。接受 dolutegravir 者维持每日 850mg、其他人逐步到 850mg 每日两次。35 人 ANCOVA 还调整多个协变量，模型稳定性待审。
- **强度与界限**：B 的宽区间不排除临床相关大小的正负变化，也不证实二甲双胍对相关人群绝对无效；A 是分选单核细胞、B 是全血，受试者、持续时间和对照不同，不能简单称为同一效应的成功/失败复制。B 未报告延寿；5 名未纳入符合方案分析者仍属于原随机分母。
- **新冲突 X26**：来源 A 正文 EpiTOC 同一组内报告 P=.003 且 95% CI −0.003 至 +0.008；若二者确系相同参数和通常双侧检验，存在明显不一致。也可能有检验尺度/方法不同或笔误；补充图与代码未核，暂不引用该组 P 或区间作为确定证据，不臆造更正。

### C000016｜同一克隆的命运改变，不等于自动证明干预能修复

- **来源**：[Cellular & Molecular Immunology 2024](https://www.nature.com/articles/s41423-024-01225-y)，读摘要、Results/Fig. 3–4 相关网页文字，未核补充原始数据与代码。研究在小鼠移植模型中以遗传条形码追踪克隆，在移植后 9 月与 12 或 15 月比较输出；按末次 B/粒细胞比例划分早/晚表型。作者称约 60–70% 克隆谱系偏向稳定、30–40% 改变。晚表型部分克隆相对淋巴倾向来自**粒细胞产出减少**，不必是淋巴产出增加。
- **穿透点**：在有克隆追踪的模型里，群体变化既可来自不同克隆贡献，也可来自同一克隆输出偏向改变；“身份稳定=状态稳定”与“相对比例提高=绝对数增加”都不成立。
- **边界**：原试验涉及移植、遗传标记及按终点形成的组别；单个克隆/细胞不是独立动物样本，克隆追踪不等于追踪同一物理细胞，不能直接外推自然人体造血或干预因果。文中 30 只排序、分析子集 13+12，另一些排除/缺失须核附录，不默认分母相同。

### C000017｜组成信号可以是真信息，也可以影响观测解释

- **来源**：[Genome Medicine 2026](https://pmc.ncbi.nlm.nih.gov/articles/PMC13632308/) 摘要、Methods/Cohorts、Results/Fig. 6–7 和 Table 2；未复算。
- **4,058 人的 DNAm 派生组成**：六时钟中，年龄读数变异最高 53% 与估计细胞组成相关，年龄加速最高 21%。来源还用已分选细胞数据构造**计算机模拟混合**，而不是物理混血或人体干预。18,859 人另用于与 176 个结局的关联分析；部分时钟的关联经组成调整后平均仅小幅衰减，年龄加速对死亡风险的表中 HR 并未一律消失。
- **结论边界**：构成在样本/特定模型里可影响读数，不可把最大解释方差 53% 当作每个人干预变化的份额；调整估计组成后的关联也不证明细胞内因果或替代效度。组成既可能反映真实免疫生物学，也可能影响我们想测的另一概念，角色需在分析前定义。

### C000018｜强反例：血压不是“分子指标没有意义”

- **来源**：[BPLTTC, Lancet 2021, 开放许可论文](https://www.wrh.ox.ac.uk/files/pharmacological-blood-pressure-lowering-for-primary-and-secondary-prevention-the-lancet.pdf/@@download)，读摘要、Methods/统计、Results 解析文本；未复算 IPD。48 项随机药物比较、344,716 名参与者，排除已知心衰者；随访中位 4.15 年。每 5 mmHg 收缩压差标准化的主要心血管复合事件 HR：基线无心血管病 0.91（0.89–0.94），已有病 0.89（0.86–0.92）。研究把不同随机比较的效应按**组间血压差**标准化，并有试验层面的 meta-regression；不是把个人降低 5 mmHg 的独立因果效应测出来。
- **设计含义**：药物降低血压与临床事件存在跨多个试验的证据，挑战对所有生物读数一视同仁的怀疑；但不同药的非血压效应、绝对风险、不良事件与适应证仍重要，不能据此给所有人降压、更不能把“5 mmHg ≈ 10%”迁移到任何个体或衰老时钟。不是正式代理资格证明。

### C000019｜功能干预的边界：长期照护机构跌倒 RCT

- **来源**：Taylor 等，Staying UpRight，[作者机构摘要](https://openrepositorydev.aut.ac.nz/items/5246658f-cd69-42f0-84e7-f8e94820f4e1)、[期刊 PDF](https://www.jamda.com/article/S1525-8610(23)00909-X/pdf) 摘要与部分 Results；未核协议、附录或原数据。新西兰 25 个长期照护机构、520 名居民个体随机，12 月理疗师带领平衡力量 vs 时长匹配坐姿活动；跌倒率 IRR 0.98（95% CI 0.76–1.27）。疫情中断，平均出席约 26 小时。
- **解释**：该试验没有显示跌倒率减少，也没有证明效果为零。实施中断是重要可能解释，非已证实的中介机制；按参与程度的事后比较不能恢复随机化。不能推广为所有运动无效，也不能把 CAPABLE 或 LIFE 的功能获益移植到任何住院/机构人群。设施与参加者层级要在未来分析里显式处理。

### C000020｜算法快照：缺失处理可能让单一样本结果依赖同批其他样本

- **来源与版本**：METFORAGING Methods 引 [DunedinPACE 官方 GitHub](https://github.com/danbelsky/DunedinPACE)；本轮获取当前可见 commit `4b569983543e51d1022aecec9a25e694bb3a336a` 的 `R/PACEProjector.R` 与 GPL-3.0 LICENSE。以 GitHub contents API 和 Git blob API 分别拉取、逐字节比较并重算 Git blob SHA-1 与本地 SHA-256；[manifest](source_snapshots/dunedinpace_4b569983/manifest.json)。**论文没有明确该 commit；不能声称就是该试验运行的版本。**
- **文本级观察**：代码默认覆盖阈值 0.8，识别到特定 EPICv2 行名后设为 0.7；缺失值按条件用该批次非缺失均值或训练参考均值填补，随后用参考向量做分位数标准化、权重和截距计算。是否触发及效应方向取决于具体缺失模式、批次、矩阵和版本；本轮未运行 R 包或核数据/依赖完整性。
- **含义**：给定同一目标样本的观测值，若其某些探针缺失且使用同批均值填补，替换同批其他样本有可能改变填补值和最终分数；这不是个体真实生物变化，也不证明任何已发表结果受该问题影响。平衡样本批次、冻结代码/权重/依赖与批处理规则，分别做联合/分批敏感性分析。变化小或没有缺失时，该风险可很小或不存在。

## 三｜可运行的非识别反例：同样的总体变化，两种完全不同的机制

运行 `python knowledge_base/experiments/mixture_identifiability_demo.py`。以下所有数字均为人工数据：设两类细胞的分数都是 0–1，总读数是它们的加权均值，基线比例 (0.75,0.25)、类型均值 (0.20,0.80)，总数 **0.35**。

- 世界 A：比例变为 (0.25,0.75)，类型均值不变；总数 **0.65**，+0.30 全是构成项。
- 世界 B：比例不变，类型均值变为 (0.60,0.80)；总数也为 **0.65**，+0.30 全是类群内项。

只观测两时点总体均值，不能区分 A 与 B；这是**信息不足**而不是算法偏差。记录组成、各类分数、绝对计数和采样机制能收窄解释，但不能自动证明同一物理细胞变化或治疗因果。对固定类别和线性混合有精确恒等式：

`ΔM = Σ p₀ Δm + Σ Δp m₀ + Σ Δp Δm`。

该等式不自动适用于经过分位数标准化及非线性处理的整套时钟，也不提供唯一因果分解；其他参考点/路径会重新分配交互项。代码另以 0.3 vs 0.7 的**玩具样本均值插补**说明批依赖，不是上述官方算法运行或真实时钟效应。

## 四｜让“值得过的生活”进入研究，而不把人变成平均数

1. **结果向量而非单个总分**：预先同时报告死亡/严重损害、行动任务、受试者自选目标、照护负担、支出/可及性；不要把这些直接相加，除非明确权重来自谁、何时及如何处理分配冲突。
2. **效用与公平分开**：一个低成本项目即便平均效益好，也可能因门槛、交通或数字能力让受益集中；测资格、可用、接受、完成与长期收益的漏斗，并保留拒绝参与的权利。单纯比较使用者会遭选择偏差。
3. **暴露与功能分开**：跌倒每人年和每行走小时率回答不同问题；更愿意出门的人可能暴露更高。不能只优化跌倒数而以减少有价值活动为代价。活动本身、伤害及人是否愿意出门要并报；死亡是竞争事件而不是普通失访。
4. **分子异常也可能重要**：不把“人更能走”作为忽略免疫、癌变、骨损或其他长期损害的理由；长期危害与短期功能可能方向相反。

## 五｜下一阶段的决定规则（均为提案，非已审定结论）

- **否决 A：单一时钟万能。** 找到同一人群、多干预、多队列下预测和临床效应不一致即限制其语境；反例之外不得推成所有时钟无效。对血压案例积极寻找既能改指标又增加临床风险的药物反例，并核正式监管资格。
- **否决 B：环境总是更高杠杆。** 在公平分配资源、同人群、等期限比较生物干预与环境干预的风险—收益和可及性；若生物干预净收益更大，不保留环境优先的先验结论。现有不同研究不能得出该排序。
- **否决 C：同一细胞可从组均值确认。** 必须增加身份或谱系、细胞绝对数量、存活/迁移与功能挑战；若只能观察克隆，明确分辨克隆身份与物理细胞身份。
- **否决 D：“不显著=无效或安全”。** 预先由临床/参与者利益相关者确定最小重要差异、非劣界值、风险和功效；必要时按停止规则继续追踪，不凭事后区间制造阈值。
- **硬门槛**：X18–X26、数据缺失、混杂和权利须逐项处置；D05 真实独立外审之前不定书／三论文最终架构。本轮并未安排或完成外审，也未覆盖所有已有债务。
