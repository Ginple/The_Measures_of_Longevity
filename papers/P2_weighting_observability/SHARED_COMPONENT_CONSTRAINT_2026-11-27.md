# P2｜跨时共同组分：逐时点界限何时不再锐

状态：基于 PR1@[`e4b4ed0`](https://github.com/Ginple/The_Measures_of_Longevity/blob/e4b4ed056dc9a7334235f04980666462116f9a74/knowledge_base/experiments/P2_ADDITIONAL_MEASUREMENT_BOUNDS_2026-11-27.md) 已有附加测量模型的**本地条件延伸**；不是声称新定理、独立外审、生物效应或统计置信区间。PR 已提醒跨时共同约束可能让逐时点端点组合不再锐，本例具体写出一个可解的共同组分模型。它与[捕获份额模型](BINARY_CAPTURE_IDENTIFICATION_NOTE_2026-11-27.md)的变量及目标不同，不可互换。

## 假设和可行域

精确线性模型 `y_t=p_t*x1_t+(1-p_t)*x2`，`t=0,1`；`y_t,x1_t,x2∈[0,1]`、已知 `0<p_t≤1`。额外假设两时间的类型 2 数值**严格相同**，且 `x2∈[a,b]⊆[0,1]`。这不是仅仅在两个时间分别说 `x2_t∈[a,b]`，也不是相同细胞得到了追踪。对每个 `p_t<1`，由 `0≤x1_t≤1` 得：

`(y_t−p_t)/(1−p_t) ≤ x2 ≤ y_t/(1−p_t)`。

把各时点约束与 `[a,b]` 相交得到闭区间 `[L,U]`；`p_t=1` 时，该点不约束 x2（而 x1_t=y_t）。若 `L>U`，共同假设与读数冲突，应报告无解；本实现有意拒绝 `p_t=0`，不能直接用下面除以 p 的公式。

对可行的 x2，`Δx1=(y1−(1−p1)x2)/p1−(y0−(1−p0)x2)/p0` 是 x2 的仿射函数。因此 `[L,U]` 两端产生它的最小、最大值；分别代回式子产生满足所有条件的共同 x2、x1_0、x1_1，界限可达。只要共同可行域非空，这些端点就是**写明的无噪声联合模型**的锐界。见[精确有理数脚本](../../knowledge_base/experiments/shared_type2_bounds.py)及[有限网格与端点见证测试](../../tests/test_shared_type2_bounds.py)；测试不代替独立证明。

## 同一个观察，不同的合同

取 PR 示例 `p0=p1=1/2`、`y0=3/5,y1=2/5`，两个时间类型 2 都被外部限制在 `[2/5,3/5]`：

- 无跨时共同条件时，PR 的逐时点构造得到变化锐界 `[−3/5,−1/5]`。
- 再要求同一个 `x2`，可行 `x2∈[2/5,3/5]`，由两个混合式相减可得 `Δx1=(y1−y0)/p=−2/5`。这是**在强共同假设下**的点识别，不是一个实测个人下降量。
- 若改 `p1=1/3`、其他不变，共同模型得到 `Δx1∈[−3/5,−2/5]`：权重变化时即使 x2 共同，点识别不必保留。
- 单独每时点都可行也不保证共同模型可行。例如 `p0=p1=1/2`、`y0=0,y1=1`，逐时点需分别 `x2=0` 和 `x2=1`，因此没有共同值；不能凭逐时点区间强行生成联合结果。

## 双混合反演与权重误差：互补而非同一任务

PR1@[`94ce2ff`](https://github.com/Ginple/The_Measures_of_Longevity/blob/94ce2ff0237597a040ad96c0e0b2b5f3e243c0a7/knowledge_base/experiments/P2_TWO_MIXTURE_INVERSION_2026-11-27.md) 进一步讨论在**同一组分**上取得两个不同、精确权重读数：`p_a≠p_b` 的线性方程可点识别两个组分，但权重接近会放大读数误差。其既有[精确算术实现](../../knowledge_base/experiments/two_mixture_inversion.py)和[测试](https://github.com/Ginple/The_Measures_of_Longevity/blob/b8434e22ec62ba21814546560a33fc38f4939e9f/tests/test_two_mixture_inversion.py)已择取，标注远端来源；那是同一组分两种测量，而不是上文两个时点类型 1 的变化。

一个本地补充的人工校准反例说明读数误差界不包含权重误差：真实组分 `(x1,x2)=(.8,.2)`、真实权重 `(.50,.51)` 产生精确读数 `(.500,.506)`；若误把第二个权重当 `.52`，模型可行且反演成 `(.65,.35)`。此时读数误差为零的公式界是零，但类型值各错 `.15`：没有违反 PR 的界，因为它明确假设权重准确。这不是某真实平台的误差量，也不是权重误差的一般锐界；见[回归](../../tests/test_inversion_weight_calibration.py)。

## 真实应用前必须支付的代价

共同 x2 是生物和测量强假设：类型定义、状态、检测误差、样本来源、批次和时间变化均可使其失效。尤其是在干预可能改变类型 2 的情况下，强制其不变会人为压窄界限。单独测量或数据驱动区间有采样和校准误差，需事先建联合统计覆盖及敏感性分析；`p≈0` 时除法放大误差。不能把此条件界直接用于非线性年龄钟、细胞个体身份或临床因果效果。该例没有患者级数据、实验验证、系统先行文献比较或独立同行评议。
