# P2 KERNEL｜汇总、权重与检测

**工作草案，非投稿稿。** 见 [PROTOCOL](PROTOCOL.md)。

- 问题：在已定义固定类别下，观测平均值变化可以有多大比例来自类别内读数、构成或观测权重？不声称分解就是因果机制。
- 基础：归一化权重 p_ti≥0、Σp_ti=1，M_t=Σp_ti x_ti。对同一固定类别和可比标度，ΔM=Σp0 Δx+Σx0 Δp+ΣΔp Δx。此三项依赖选定基准，交互项不可省略；类别出现/消失时需重新定义。没有类别配对数据，项通常不点识别。
- 反例：[人工脚本](../../knowledge_base/experiments/mixture_identifiability_demo.py) 同样 0.35→0.65，可全部由组成或全部由类内均值变化构造；并非个体层面观察，也非真实生物数据。
- 正反证：有固定外部权重、校准回收率与各类别结局后，某个纯权重模型不足以解释数据；但固定处理后组成可能阻断真实中介、引入选择偏差，不能直接当总治疗效应。批次、绝对数、拷贝数、误分类及不确定性须预先测量。
- 非线性指标须独立建立模型；队列插补/归一化会使同一标本结果受其他样本影响，不能仅凭线性等式推断具体时钟变化。代码快照不证明试验所用版本。
- 下一门槛：估计目标与观测机制合同、明确可行界限、在预先约定条件下可复算的数据；P1 是身份/生存，P2 是测量算子，P3 是结论治理。
- **2026-11-27 会计增量**：[推导与可运行精确算术](DECOMPOSITION_NOTE_2026-11-27.md)展示同一总变化 +0.24 在基线参考下类内项 +0.54、在末期参考下 −0.24；对称分配为 +0.15。交互项分配是约定而非因果机制，非线性时钟不得直接套用。
- **2026-11-27 相对捕获权重的条件识别界限**：[两类模型推导](BINARY_CAPTURE_IDENTIFICATION_NOTE_2026-11-27.md)在已知类别、正相对权重区间和精确观察比例下给出总体组成变化的锐界；例中非共享权重为 [−1/7, 1/2]，额外假定跨时权重相同则为 [5/28, 1/5]。是假设敏感性的合成演示，不是置信区间、单细胞身份、因果效果或真实时钟复算；已有选择偏差研究的先行工作比较尚未完成。
