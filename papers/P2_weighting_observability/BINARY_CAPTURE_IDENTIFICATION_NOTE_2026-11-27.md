# P2｜两类捕获不均：可实现的识别界限

**状态：项目推导和合成例；不是新数据或声称首创。** 该问题与选择概率、选择偏倚和敏感性分析已有大量研究相通；尚未完成系统先行研究比较或独立数学审阅。这里的贡献候选是将可校准的“相对捕获权重”限制显式接到长寿测量合同，并展示共同与独立跨时权重假设的差别；是否足以支持独立论文仍待比较与审稿。此文计算的是**群体组成**，不识别同一细胞内的返老变化，也不在本文建立临床疗效。

## 合同与推导

在每个时点，设基础总体中类型 1 的比例为 `p_t`（类型 0 为 `1-p_t`），类型特定的正相对捕获效率为 `e1_t,e0_t`，观察到的类型 1 占比 `y_t` 是总体规模乘权重后的确定性比例：

`y_t = p_t e1_t / (p_t e1_t + (1-p_t)e0_t)`。

令 `r_t=e1_t/e0_t>0`，只需相对权重，代数反解为 `p_t = f(y_t,r_t)=y_t/[y_t+r_t(1-y_t)]`。在 `0<y<1` 时，`f` 关于 `r` 严格递减；在 `y=0,1` 时为常数。假设观察 `y0,y1` 精确且每个 `r_t∈[L,U]`、`0<L≤U<∞`：

- **各时点比例可独立取值**：`p1-p0` 的锐界为 `[f(y1,U)-f(y0,L), f(y1,L)-f(y0,U)]`。上下界分别由 `(r0,r1)=(L,U)` 和 `(U,L)` 达到。这里“独立”是可行参数集合为矩形，不是统计独立性假设。
- **跨时比例相同**：若额外强加 `r0=r1=r`，`r∈[L,U]`，则对 `g(r)=f(y1,r)-f(y0,r)` 在区间上优化。内部时点值与端点值都要检查。若 `0<y0,y1<1` 且二者不等，写 `k_t=(1-y_t)/y_t`，唯一内部驻点为 `r*=1/√(k0 k1)`，如果在区间内也要比较；一端是 0 或 1 时无内部驻点、相等时差恒为 0。极值可直接在所列可行 `r` 上取得，所以也是该限制下的锐界。

证明可实现：对任意有限正 r，可选 `e0=min(1,1/r)`、`e1=r·e0`，两效率均在 `(0,1]`。由反解构造 p 并代回就产生相应 y；有理数 p、e 可通过足够大的有限人工总体近似或在可整除的情况下精确实现。这里的“锐”仅针对写明的确定性模型及其参数集合，含无穷小数时不保证固定有限样本的精确整数实现。

## 可重放例与检验

取观察 `y0=.4, y1=.6`，每时点 `r∈[.5,2]`。独立取值下：

- t0 的总体比例在 `[1/4,4/7]`；t1 在 `[3/7,3/4]`。
- 总体变化锐界为 `[−1/7,1/2]`，包含负、零、正；观察比例增加不决定总体比例变化的方向。
- 若强制相同 r，变化为 `[5/28,1/5]`。两个端点取 r=.5 或 2，最大值取 r=1；方向在该强假设下才确定。
- 当观察两时点均为 .4，共同比例模型给出精确零变化；独立比例模型仍允许变化。这样一个假设可改变结论，不是无需支付代价的“校正”。

[脚本](../../knowledge_base/experiments/binary_capture_bounds.py)使用高精度十进制计算驻点；[测试](../../tests/test_binary_capture_bounds.py)对端点、边界值、正反方向和离散参数网格进行回归。网格只是有限检查，解析推导给出连续区间候选极值；同开发者测试不等于独立证明。所有数字为人造示例，**不是置信区间**。

## 何时不适用

1. 模型假设类别可准确识别，组内捕获权重与其他特性无关联，数据可以看作同一基础总体下的加权份额。错分、每个细胞不同拷贝数、时间内细胞分裂或死亡、跨批次归一化及未测类别均可破坏这个模型；不能把它直接套到实际 bulk VAF 或非线性年龄钟。
2. 即使确定总体比例变化，也不识别各实体的纵向身份、分裂、状态转变、治疗因果效应或功能结局；P1 的配对身份问题与 P2 的观测权重问题不可互相替代。
3. `L,U` 必须来自可转移到相同组织、状态、批次和处理条件的校准，且校准数据本身存在误差。若是估计区间而非绝对已知界，必须预设联合不确定性与覆盖方式，不能直接把识别界限报成 95% CI。共享比例尤其需要跨时漂移数据；相同实验室或平台不是证明。
4. `y=0/1` 的确定性边界不适用于有限样本中“观察零例即总体零”；计数噪声、零捕获和有限总体量化应另建抽样层。
5. 若类型界限依赖处理或检测，固定构成的再加权仅是标准化描述目标，不自动是随机化总效果、直接效应或机制效应。

## 可证伪的研究路径

先注册对象、类别、时间和目标，独立标记或 spike-in 校准各时间/状态的相对捕获，盲态保留批次、QC、绝对计数和阴性对照；先绘制可行权重区间，再报告点估计与上述条件界、跨时共享假设及更保守非共享范围。检查某批次里是否存在可观察的类型混淆、零捕获、平台依赖；任何一项足以使两类简单合同不适用。只有在获得授权的真实配对样本、完整元数据和独立复核后，才能把该合同用于具体研究；当前没有执行。

## 先行文献的一次局部查验

[Zetterstrom 2024](https://www.degruyterbrill.com/document/doi/10.1515/em-2023-0033/html) 的摘要和引言明确将选择偏倚界限与可指定的敏感性参数作为既有研究方向，并提出基于未观测结局概率的因果界，与这里的观察类别份额不同；该文亦引用更早的选择偏倚界限。我们这里只核读摘要、引言，并未逐式比较，也未证明本两类反解或共享权重界是新定理。投稿前必须系统追查差异抽样的逆概率加权、偏倚参数及纵向可比性先行研究；若无实质新贡献，应并入其他工作而不是独立宣称发明。
