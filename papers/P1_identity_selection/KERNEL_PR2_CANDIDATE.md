# P1 KERNEL｜身份、存活与选择

**工作草案，非投稿稿或已注册研究。** 与 [PROTOCOL](PROTOCOL.md) 配套；不假定“同一细胞”与“同一谱系”可互换。

- 问题：汇总读数改善是否识别基线实体的个体内变化？实体和分裂规则须先定义。
- 主目标：对基线定义且两时点存活可测的实体，预定结局的配对分布变化；此是描述性幸存者目标，不自动是治疗因果效应。死亡后结局未定义；若讨论随机治疗，须另定义死亡优先的复合目标或在明确假设下的 principal stratum，不将治疗组幸存者直接作可交换比较。
- 对照生成机制：同一汇总变化可由实体内变化或选择/替换产生；现有 [模拟](../../knowledge_base/experiments/mixture_identifiability_demo.py) 为**类别均值**而非单细胞配对证明。
- 分裂与抽样：遗传/甲基化条码标识克隆或谱系，不是同一细胞证据；耗竭取样不能复测同一细胞。若干预可能改写表观遗传条码，需正交、稳定的遗传标记和干预前后错分率验证。
- 可证伪：用独立标记和已校准生存/检测、功能及完整基线重新比较；若在可信的配对或谱系与绝对计数约束下纯选择模型无法解释，排除纯选择不等于证明某一种细胞内机制。
- 下一门槛：给出明确的因果 estimand 与缺失模型、构造可推翻模型、已冻结模拟与外部真实数据对照；不可用“身份标签存在”宣称本体不变。与 P2 避免重复分析主张；不满足独立增量时公开重评三篇划分。

- **2026-11-27 识别进展**：虚构有限总体边际下可计算 sharp 界限，且逐一穷举小总体检验；不限制单调性为 [−10,26]，假设无治疗致死为 [5,20]。二者皆不是置信区间；[推导与限制](SURVIVOR_IDENTIFICATION_NOTE_2026-11-27.md)。
