# 主书与伴生论文分工 / Book–paper publication map

**三项都是候选研究计划，不是本轮完成/可直接投稿的论文。** 与主书共享来源和断言ID，但各自预设问题、分析单位与可推翻标准；不能把一章换标题拆成论文。不能同一结果多次作为独立新贡献发表；投稿时披露与书稿及其他稿件重叠。

## 时间与依赖 / Sequencing

P1/P2可并行做形式化和数据接收；P3先冻结评价协议，再增加复杂输入，不能用已见攻击既开发又做唯一测试集。书稿不必等待三篇论文发表，但必须准确标记其未验证状态。

P1的身份条件与P2的权重条件可能耦合，但**一个回答“是同一个谁”，一个回答“汇总量代表什么”**。如果最终形式化/数据无法形成独立贡献，应合为一篇，不为了数量硬拆。

投稿目标类别仅建议：P1概念与方法/老化生物学，P2测量与统计方法，P3研究软件/开放科研方法。未进行期刊范围、费用、注册报告、预印本及版权政策逐刊筛选，暂不承诺目标刊或接收概率。
