# P3 KERNEL｜证据改变时，哪些判断应失效

**工作草案，非性能认证。** 见 [PROTOCOL](PROTOCOL.md)。

- 问题：绑定来源、片段、主张记录和审阅版本，能否比路径或文件 hash 单独检查更有效地发现预定义过期状态？只检测可编码契约，不能判科学真值。
- 单位与对照：一个带独立 oracle 的变异或非变异样例；A 路径、B hash、C +span、D +claim/review hash、E +类型/执行计数。冻结规则与评测后再运行未见攻击；开发样例是回归集，不是盲测。
- 主要报告每攻击族 TP/FP/FN/TN、未判定/拒绝率、人工及运行成本；按项目簇聚合或抽样，未明确独立性前不按测试函数数充样本量。对 oracle 分歧保留裁决记录。
- 两类硬反例：无关内容更新引起误报；来源或主张变动而人审绑定不失效引起漏报。程序通过不等于审稿人独立、内容真实、系统安全或临床可靠。
- 下一门槛：独立的第二项目与盲态攻击者、权限与敏感信息审查、复现回执；当前无独立评测、外审或发表结论。

- **2026-11-27 评价设计**：[评价合同](EVALUATION_DESIGN_2026-11-27.md)区分可编码契约与科学判断，并规范拒绝率、基准泄漏和逐项目独立性；其配套指标代码只运行虚构样例，未进行独立评测。
