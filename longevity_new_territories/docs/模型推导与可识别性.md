# 两个最小模型：只生成可证伪条件，不冒充新生物发现

## 一、输出不是终端处理

对一种已定义、可追踪的cargo，设L为输出源内存量，P为转运中存量，R为接收者内未终端处理存量，Q为累计已转化/失活/离开研究边界的量：

```
dL/dt = g − (k+e)L
dP/dt = eL − uP
dR/dt = uP − V R/(K+R)
dQ/dt = kL + V R/(K+R)
```

g为生成，k为源内处理，e为输出，u为摄取，V为接收端最大处理通量，K为半饱和常数。每一项单位必须一致。模型中d(L+P+R+Q)/dt=g；这守恒的是所定义cargo或示踪当量，**不是“生物损伤”“衰老”或健康价值**。降解后同位素仍可能存在于产品中，Q必须用预定义产品/排出边界测量，不能由荧光变暗自动认定。

稳态源L*=g/(k+e)，源外输出J=ge/(k+e)。当J<V，R*=KJ/(V−J)；J≥V则本模型无有限接收端稳态。这是模型的容量条件，不是已在人类测到的相变或安全阈值。

在有限稳态内，T*=L*+P*+R*对e的导数：

```
dT*/de = g/(k+e)^2 × [ −1 + k/u + k K V/(V−J)^2 ]
```

故源内cargo随e下降，但总滞留cargo可以增加，甚至不需要超过最大容量。模型示例V=.95时，总滞留从2.4667增至5.125，源从2降至.625；都只是人为无量纲参数，不是TBX3或线粒体真实估计。不同位置cargo危害不同，T也不是净健康分数。

若固定总细胞数、克隆比例x，WT与高输出克隆单位通量分别jW/jM，且jM>jW，则总输出J(x)=(1−x)jW+x jM。在jW<V<jM时：

```
xcrit = (V−jW)/(jM−jW)
```

演示jW=.2、jM=.75、V=.55得xcrit=.63636。这个数不能移植成人体克隆阈值。它仅指出应同时测**克隆负荷和接收端余量**，而非只测前者。容量随年龄、克隆本身、炎症变化或cargo身份转变时，公式必须重估；克隆扩张的细胞出生/死亡还须额外质量流项，本轮没有把静态x混合公式冒充动态质量守恒。

更深的候选问题：若克隆适应性主要取决于自己降低了多少cargo，而接收端代价由所有细胞共同承担，局部选择可能推动输出通量趋近甚至越过公共处理容量。这接近既有公共品/外部性理论，**不是新数学定律**；未知之处在于哪些具体组织真满足这些条件、选择成本是否抵消收益。

## 二、同样干预成分，为什么顺序可能不同

最小生态模型设x为突变克隆比例，z为生态位不良状态。N只降低z，R代表泛化再生刺激，只在R期发生竞争：

```
d logit(x)/dt = R(t) [−.2+b z]
dz/dt = −a N(t) z
```

两阶段各时长T，N、R总暴露相同。若N→R与R→N，最终z相同，但：

```
logit(x_NR) − logit(x_RN) = b T z0 (exp(−aT)−1)
```

b=0时严格无顺序差异，这是负对照；b反号，偏好的顺序也反号。不能从这个模型推出普遍“生态位先修”或任何实际药物的给药顺序。

演示x0=.1、z0=.9、a=1、b=.6、T=2：N→R最终x=.07936，R→N为.17987，而最终z均=.121802。两组都没有对应真实药物或剂量。结果是给定模型的条件后果，不是独立支持假说的实验数据。

这里的机制是生态位改变了相对增长率；如果只是两个固定、相互独立的对角增长/清除算子，常常可交换，不应凭空制造顺序效应。真实实验还要排除药代、作用时长、残留、恢复间隔与初始细胞量等非生态原因。

## 测量识别底线

- cargo减少：区分生成减少、终端处理、输出、增殖稀释、死亡与检测改变。
- recipient标记增加：区分摄取、完整细胞器整合、降解滞留和黏附，不能一律叫清除。
- 绝对克隆数与比例同时测：比例下降可能仅WT扩增，绝对突变负荷仍增加。
- 生态位变年轻与特定突变更不适应不是同义词；2026 β-catenin论文比较不同组织环境，并没有直接证明所有实际年轻化干预可逆转已扩张克隆。
