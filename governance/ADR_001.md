# ADR-001 / 联邦分层与诚实门禁 / Federated layers and honest gates

日期2026-11-25。状态：本轮本地实现的暂定决策；维护者仍可显式修订。不是远端仓库设置或人工发布批准。

## 决策

1. 一个长寿研究monorepo；通用方法作为独立版本组件。暂不用submodule，确保解压即可复跑；抽离独立包前不维护两份活跃SSOT。
2. 书/论文通过共享claim ID引用同一证据判断；分支草稿可以不同，不得各自重新签成互相冲突的“已验证事实”。
3. 第三方附件只记录接收hash和采纳意见，不自动执行、不作为顶层指令，也不随包再分发其全文。
4. 修复冻结包发现的缺口：原0.1.0保持不动，新副本0.1.1候选；改变supported维度合同须写兼容性说明，旧断言需人审迁移。
5. 固定min_ran>=1，blocking skipped/not_applicable不算通过；经人工批准的新合同可另设非blocking项，但不得失败后偷偷改标。
6. 比例采用estimand分派；合法舍入不能被“必须精确整数k/N”误杀，加权估计需另查而非绿灯。
7. 外审未做时明确阻断正式学术认证；本轮可交付工程候选与研究提案。软件发布和学术主张发布分开。
8. 不生成HTML。原历史基线仅只读验证，不调用旧prepare_bindings或刷新基线工具。

## 后果 / Consequences

代码稍多但边界可测。没有声称权限隔离、远端分支保护或自动人工批准。正则hook只可作提示/早期拒绝，不作为完整安全边界。没有独立外审者身份验证服务。

下一项应由未参与构造的审阅者提供新攻击与标注；若无人参与，继续称自查，不把不同模型等同独立。
