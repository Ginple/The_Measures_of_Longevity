# 估计目标与数据接收合同 / Estimands and data acceptance

## A. 功能获益 / Functional outcome

|字段|LIFE本轮登记|
|---|---|
|对象/单位|随机参与者，不是细胞|
|比较|结构化中等强度活动 vs 健康教育/上肢伸展等活动对照|
|主要结局|首次重大行动障碍，含预定义替代裁定|
|时间|随访各异；平均接触随访2.6年|
|估计器|报告的分中心/性别分层Cox ITT HR；本轮不重拟合|
|另可复算|原始事件人数/随机人数的粗比例、粗差及粗RR|
|不能互换|HR、RR、固定时点风险差、死亡风险和生物年龄|
|缺失/删失|原文有删失与IPW敏感性分析；本轮未重跑、未批准其全部假设|
|获益/危害|功能信号、安全性、死亡、长期价值分别记录|

如果要进一步估计统一时点NNT，需预设时间点、从适当生存/竞争风险估计得到两组风险、报告差及不确定性，并解释死亡等事件的处理。不能只把mean follow-up当horizon。

## B. 可见性与加权 / Observability and weighting

在简化线性分子混合模型里，f为真实携带细胞比例，h为其细胞内突变比例，r为相对有效分子贡献。bulk B不是f，也不是h。参数单位与测量算子先定义，再讨论识别。

### P1所需

稳定身份/谱系映射，分裂/替换规则、基线完整登记、失访和独立死亡标记、批次/追踪错误率。只有存活者末次测量不能识别全基线群体效应；死亡后结果可能未定义，不能无说明填数。

### P2所需

尽可能同一供者/组织/时间点的bulk与单细胞配对、cell/variant crosswalk、mtDNA拷贝数、文库/捕获效率、覆盖与过滤阈值；报告检测不到而非断言不存在。未取得数据时，构造世界只能表明可能性，不裁决真实效应。

### 接收拒绝项

只有汇总图、年龄时钟分数、未配对的不同队列、缺版本/过滤记录、用“lost”当已证实死亡、用名义细胞ID作有序数值、只按细胞数量作独立供者样本量，均不得自动升级为所需金标。

## C. 已知与未知 / Unknowns

已知未知：原研究数据/完整方法未重新分析，样本内细胞分布与身份配对缺失，copy/capture分离尚缺。未知未知保留为未分类异常日志与外部审阅问题，不因当前本体缺边就宣布科学空白。
