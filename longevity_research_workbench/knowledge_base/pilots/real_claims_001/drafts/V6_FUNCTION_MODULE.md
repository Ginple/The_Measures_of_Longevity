# 示范模块A：先保住走路的能力，而不是先证明年龄逆转
## Function before an age-reversal claim

**状态：证据约束型草稿，待人类与独立审阅，不覆盖V6原文。**

共享断言：**LON-C000001**。主书拟用位置：第二部身体功能、 第七部判断与行动。当前证据是发表报告与本轮有限提取，不是重新分析参与者数据。

长寿研究可以从一个不宏大、却重要的问题开始：一个原本还能独立行走的人，能否更久地保住这项能力？LIFE试验比较结构化身体活动与健康教育，纳入1,635名70–89岁、久坐、有下肢功能限制但基线仍能完成400米步行的志愿者。这个人群既不是所有老人，也不是已经无法行走者的代表。[原始研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC4266388/)

研究报告，平均随访约2.6年，身体活动组246/818、健康教育组290/817出现重大行动障碍，分别约30.1%与35.5%；按随机分配分析的Cox危险比为0.82，95%置信区间0.69–0.98。这支持在该试验情境下认真对待结构化活动的功能价值。它没有测出“年轻几岁”，也无需先证明逆转细胞年龄，才能使保留行动能力成为有意义的目标。

但数字不能随意互换。由原始事件人数复算，两组粗事件比例相差约5.42个百分点，粗风险比约0.847；它们都不是Cox危险比0.82。这里的2.6年是平均随访，不是每名参与者统一的观察时点。因此，本模块不把粗比例倒数包装成精确的“2.6年治疗获益人数”。

结局也比“所有人都现场走不了400米”复杂。研究有明确的15分钟等测试规则，并允许在不能现场完成评估时采用替代裁定；536例首次主要结局中，74例来自替代裁定。说它是功能性结局是恰当的，说它完全没有测量和缺失问题则不是。

最后，行动获益不能自动升级为延寿或无害。研究对死亡的判断仍不确定；严重不良事件的风险比区间也容许获益或损害。这里既不因死亡未显著改善而抹去行动价值，也不因行动改善便删除安全性和长期结局。对人的建议还需要结合适用性、医学状况与可执行条件，而不是从一项试验生成统一处方。

**本模块不主张**：已证实延长寿命；证明返老还童；适用于所有年龄和疾病人群；教练、交通补贴或问责机制已被分别随机识别为有效成分。
