## 复建

环境Python 3.13。安装requirements.txt后：

```bash
python -m pip install -r requirements.txt
python build.py
python -m playwright install --with-deps chromium
python qa.py
```

build.py只依赖包内正文、审计、template_style.css；默认运行已有样式不需要原上传模板。若删除CSS，才会尝试从原工作区上传文件提取；因此便携复建请保留包内CSS。

qa.py中的“V6未覆盖”检查需要相邻历史longevity_v6/STATE_DASHBOARD.HTML；独立解压包没有V6时，应视为该历史校验不可运行，而非产品失败。其他检查可移除该单项后运行。本文不把不可运行的外部历史项冒称为便携测试通过。

HTML里下载功能在某些严格沙箱预览中可能被平台限制，直接下载提供的MD/JSON文件即可。外部来源只在点击链接时打开；离线内容不依赖它们。
